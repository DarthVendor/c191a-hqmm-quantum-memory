# Quantum Memory for Sequential Prediction (C191A Fall 2026)

Group project: Alex Tan, Manfredo Ochoa-Aragon, William Noon.

Question: how does quantum coherence in a model's memory change the representation of a classical random sequence, compared with a classical hidden Markov model (HMM), and which resource comparisons justify calling a quantum model "more compact"?
